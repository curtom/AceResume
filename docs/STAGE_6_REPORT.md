# 阶段 6：AI 与 RAG 交付报告

> 状态：已完成，待项目负责人审阅；未进入阶段 7  
> 日期：2026-09-26  
> 范围：模型适配、Embedding、用户隔离检索、受控建议、来源引用、人工确认、SSE 与 AI 安全评测

## 已交付

### Provider 与配置

- 新增独立 `ai-core` 包，定义供应商无关的 `ChatModelProvider`、`EmbeddingProvider`、结构化输入输出和确定性安全规则，未引入供应商 SDK 或 LangGraph。
- 实现 Qwen OpenAI 兼容适配器和明确标记的 Mock Provider；本地默认使用 Mock，服务端才读取 `DASHSCOPE_API_KEY`，前端不接触密钥。
- 按已确认 ADR 固定 `qwen3.7-plus`、`qwen3.7-text-embedding` 和 1024 维向量；Provider、Base URL、超时、Top K 与最终上下文数量均由环境变量配置。
- 模型 JSON Object 先经过共享 Zod Schema 校验；超时、限流、内容审核、无效结构和一般上游异常映射为稳定错误码。

### Embedding 与用户隔离检索

- 新增 `document.embed` 队列；材料解析完成后异步生成 Embedding，并记录模型、固定维度和完成时间。
- `document_chunks` 使用 pgvector 1024 维列；迁移显式启用 vector 扩展，没有在运行时修改数据库结构。
- 相似度查询在 SQL 层先同时限制 `user_id` 和用户本次明确选择的 `document_id`，之后才执行向量排序；结构化个人资料也重新验证所有权。
- 最终上下文结合向量名次、写作要求/JD 关键词、结构化资料、内容去重与可配置数量，并始终保留 `documentId`、`chunkId` 和原始定位信息。
- JD 只参与检索重点和表达要求，不进入事实来源、引用或事实支持集合。

### 受控生成与防捏造

- Worker 使用显式 TypeScript 状态机完成输入校验、来源检索、冲突识别、结构化生成、数字/实体校验、引用验证、候选 Patch 和人工等待，不提前引入 LangGraph。
- 每条建议包含修改前后文本、引用、支持状态、缺失事实/澄清提示、风险标记与目标 Patch。
- 确定性拦截无依据数字、百分比和关键实体；来源时间冲突、无效引用与材料提示注入均会进入风险状态。
- 上传材料始终按不可信文本处理；疑似指令行会从 Mock 生成上下文中剔除，且不会改变系统提示、调用工具或扩大数据范围。
- `unsupported` 或 `conflict` 建议不能接受；引用还会在写入前再次核对当前用户和当前生成记录。
- AI 只保存候选 Patch。用户逐条接受或编辑后，才调用普通 `ResumesService` 走版本检查和自动保存规则；忽略、重新生成和前后差异均在原型风格抽屉中提供。

### 异步任务、记录与交互

- 新增 `ai_tasks`、`ai_generations`、`ai_citations`、`ai_task_events`，保存 Provider、模型、Prompt 版本、最小必要输入、结构化建议、引用、决定和应用版本。
- `ai.generate` 使用 BullMQ 三次指数退避；任务查询和 SSE 支持 `started`、`progress`、`delta`、`suggestion`、`completed`、`failed` 与 `heartbeat`。
- SSE 将持久化事件游标与传输心跳序号分离，心跳不会导致重连后跳过真实事件；页面轮询任务快照作为恢复基线。
- AI 抽屉严格按原型语言实现事实来源、写作要求、第三方数据同意、生成进度、引用、风险、修改前后和接受/忽略交互。
- AI 异常只影响 AI 任务；简历手动编辑、自动保存、预览和 PDF 导出仍使用既有独立链路。

## 已知限制

- Qwen 真实调用通常比 Mock 慢，本次页面全链路约 38 秒；E2E 为该用例设置 90 秒总超时和 60 秒结果等待，业务页面继续显示任务进度并允许稍后查询。
- 关键实体校验使用显式规则集合与来源包含校验，覆盖当前 MVP 常见公司/学校/项目/平台/系统和技术栈；更广泛的实体类型可在积累真实脱敏失败样本后扩充评测集。
- 当前页面使用任务快照轮询恢复结果，后端 SSE 接口已完成并经过事件序列集成验证；将页面切换为原生 SSE 消费不是完成本阶段安全闭环的前置条件。
- 接受率和真实 Provider 延迟分位数只有在获得足够的真实、合规使用样本后才有统计意义；当前只报告单次脱敏冒烟结果，不将其冒充业务指标。
