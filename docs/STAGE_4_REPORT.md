# 阶段 4：模板、预览与导出交付报告

> 状态：已完成，待项目负责人审阅；未进入阶段 5  
> 日期：2026-09-26  
> 范围：版本化模板、模板中心、多页 A4 预览、分页诊断与异步文本 PDF 导出

## 已交付

### 模板引擎与模板中心

- `template-engine` 提供确定性的 `renderResume({ resume, template, theme, mode })`，浏览器预览和 Worker PDF 共用相同 HTML、CSS 与分页运行时。
- 模板声明包含 ID、版本、语言、布局、支持模块、侧栏区域、默认主题、可调参数、分页规则、字体许可与 Schema 版本。
- 新增 8 套公共模板：经典单栏、现代线框、技术聚焦、实习优先、学术简洁、石板双栏、珊瑚双栏和紧凑职业。
- 新增模板中心，支持分类信息、真实渲染的固定虚构示例、全屏预览和使用模板创建简历。
- 编辑器支持打开模板抽屉并自动保存切换结果；切换只改变模板版本和合法主题参数，结构化简历内容保持不变。
- 新增 `templates` 与 `template_versions`，内置版本以幂等方式初始化；既有版本不会被同 ID 的后续模板覆盖。

### A4 预览与诊断

- 预览运行在 sandbox iframe 中，使用固定 A4 尺寸、页间距、页边界和独立全屏预览路由。
- 共享分页器按模块条目进行分页，避免条目被直接截断；分页只操作渲染结果，不回写用户内容。
- 编辑器实时展示页数并检测内容溢出、空白页、无效链接、字体就绪状态以及超出建议/最大页数。
- 导出前弹出检查结果；溢出、空白页、无效链接、字体缺失和超过最大页数会阻止导出，超过建议页数会明确警告。

### PDF 导出

- 新增 `export_jobs`、`pdf.export` BullMQ 队列和创建、查询、下载接口；创建请求返回 `202` 与任务 ID。
- 导出任务绑定当前简历并发版本、模板版本和幂等键，同时保存创建时的不可变简历快照；这仅用于保证任务输入稳定，不恢复已取消的简历历史版本功能。
- Worker 使用 Playwright/Chromium 加载共享模板 HTML，等待字体与分页完成后生成文本 PDF，不使用截图替代 PDF。
- 内置 Noto Sans SC 字体及 OFL 许可，Worker 在渲染时嵌入字体；导出前后校验字体、分页、链接、PDF 文件头和文件大小。
- 任务默认最多重试 3 次并使用指数退避；确定性渲染错误不重试，瞬时基础设施错误可恢复重试。
- PDF 写入 MinIO 的用户隔离对象路径，下载接口再次校验所有权，并使用包含简历名称的安全文件名。
- Web 端支持任务轮询、完成后自动下载、失败提示和再次下载。

## 数据、契约与安全

- 共享契约新增模板定义、模板列表、导出请求、任务状态、队列负载和分页诊断 Schema。
- 导出任务记录用户、简历、简历并发版本、模板版本、耗时、重试次数、对象键、诊断与稳定错误码。
- 模板选择在服务端验证；简历、导出任务和下载均执行所有权过滤，跨用户访问返回不可枚举的 404。
- 相同用户、简历和幂等键重复请求只返回同一任务，避免重复生成。
- 完整简历内容、对象存储地址和底层错误不写入响应或业务日志。

## 已知限制

- 本阶段按退出条件交付 8 套模板的首个版本；模板后台发布、上下线与审计属于阶段 7。
- 导出任务已持久化，但面向用户的完整导出历史列表属于 P1/V1.1；当前编辑器提供本次任务状态、自动下载和再次下载。
- PDF 文本可选择和提取；部分 CJK 字符在第三方解析器中可能被规范化为兼容字符。浏览器视觉输出正常，如后续把“跨解析器逐字符复制一致”列为验收项，需要增加专门字体映射测试。
- 材料上传、旧简历导入、文档解析与 OCR 均未进入本阶段；其中材料能力属于阶段 5，MVP 不包含 OCR。
- 简历仍只保留最新编辑内容；`export_jobs` 中的任务快照不能用于恢复或创建历史简历版本。
