# 阶段 3：简历编辑核心交付报告

> 状态：已完成，待项目负责人审阅；未进入阶段 4  
> 日期：2026-09-12  
> 范围：多简历、结构化编辑、自动保存、离线草稿、受控样式与第一套实时预览

## 已交付

### 多简历管理

- 支持空白创建、从个人资料库选择条目创建、分页列表、重命名、复制、归档、取消归档与软删除。
- 每个用户最多 6 份未删除简历，归档仍计数；服务端在事务中锁定用户后校验，避免并发突破上限。
- 旧简历导入入口按阶段边界显示为禁用，阶段 5 再实现。
- 所有读取、保存、状态变更和删除均按 user_id 过滤，跨用户访问返回不可枚举的 404。

### 结构化编辑

- 新增独立 resume-schema，覆盖基本信息、求职意向、教育、实习/工作、项目、校园、技能、奖项、自我评价与自定义模块。
- 支持模块排序、显隐、自定义模块、条目增删与排序、撤销/重做。
- 按原型 demo 将编辑器调整为上方 A4 实时预览、横向模块切换栏和底部可收起编辑抽屉；切换模块会自动展开对应表单。
- Tiptap 富文本只开放段落、换行、粗体、斜体、下划线、列表和安全链接；数据写入前由 Zod 白名单校验。
- 内容、模板版本和主题参数分离；简历不保存整页 HTML。

### 自动保存与冲突

- 编辑立即更新内存并写入 IndexedDB；停止编辑 2 秒后自动保存。
- 展示等待保存、保存中、已保存、失败和冲突状态；网络恢复后自动重试失败保存。
- 保存携带 baseVersion 与 UUID 幂等键，服务端事务递增并发号并仅保留最新内容。
- 本地草稿与服务端内容不一致、或出现 409 冲突时，均要求用户明确选择，不静默覆盖。
- 按项目负责人确认，不创建简历历史版本；决策见 ADR 0002。

### 模板与预览

- 新增独立 template-engine，实现确定性的经典单栏模板。
- 编辑器预览区以隔离 iframe 实时渲染 A4 画布，不依赖 Ant Design Vue。
- 受控主题范围：字号 9～16px、行高 1.2～2、模块间距 6～32px、段落间距 2～20px、页边距 10～30mm、十六进制强调色。
- 正式多页分页、模板中心与 PDF 导出仍属于阶段 4。

### 原型导航与入口

- 登录后进入原型工作台，不再直接落入个人资料页。
- 工作台、我的简历和个人资料共用同一主侧栏；“我的简历”是可见的一级入口。
- 材料库、模板中心和账号设置按原型保留位置但明确禁用并标注后续阶段；未将 V1.0 范围外的“投递市场”加入产品。

## 数据与接口

- 新增 resumes、resume_sections、状态/来源/模块类型枚举及必要索引。
- 未新增 resume_versions 表；resumes.version 只用于乐观锁。
- 新增 /api/v1/resumes 下的列表、创建、详情、更新、复制、归档、取消归档、文档保存与删除接口。
- 契约与简历文档均来自共享 Zod Schema；第一套模板版本固定为 classic-single-v1。

## 已知限制

- 当前仅提供经典单栏模板的编辑期预览；真实分页、8～12 套模板、视觉回归与正式 PDF 属于阶段 4。
- 页面已按路由拆包；Ant Design Vue 等公共依赖形成的入口 vendor chunk 仍约 1.65 MB，构建会给出体积提示但不影响通过，后续按真实性能数据再拆分。
- 缩略图使用明确的占位状态，阶段 4 再生成真实模板预览。
- 浏览器关闭瞬间无法保证 HTTP 保存完成，因此以 IndexedDB 草稿作为恢复保障。
- 历史版本及恢复功能已由项目负责人取消；后续异步任务若需要不可变输入，应保存任务级快照，不恢复简历版本系统。
